04 Bon à savoir

Avant de pousser la porte.

Peut-on réserver une table pour deux ?

Pas pour le moment : seules les réservations de groupe sont prises, dans le salon. Pour deux ou quatre, venez simplement, on vous accueille au fil de l'arrivée.

Le brunch, c'est seulement le week-end ?

Non. Le brunch est servi du mardi au dimanche, de 9h30 à 19h. Vous pouvez bruncher à 16h un mercredi, c'est même conseillé.

C'est quoi, le plat du chef ?

Un plat servi chaque midi, qui change tous les jours. Pour savoir ce qui mijote aujourd'hui, regardez les stories Instagram.

Comment commander à emporter ?

Prévenez à l'avance, idéalement la veille, par message Instagram. Le formulaire juste au-dessus prépare le message pour vous.
